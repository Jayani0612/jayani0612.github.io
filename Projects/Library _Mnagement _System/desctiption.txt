📚 Library Management System
Desktop Application | Java | MySQL

Developed a desktop-based Library Management System to simplify and automate daily library operations. The application enables efficient management of books, members, and borrowing records while providing a user-friendly interface and secure MySQL database integration.

✨ Key Features
📖 Book Management
👤 Member Management
🔄 Issue & Return Books
🔍 Search Functionality
🗄️ MySQL Database Integration
🖥️ User-Friendly Windows Interface
