🏥 Hospital Management System
Desktop Database Application | MS Access

Developed a desktop-based Hospital Management System to manage patient records, doctor appointments, and hospital data efficiently. The system provides a user-friendly interface with structured database tables and forms for easy data handling.

✨ Key Features
👤 Patient Management
🩺 Doctor Management
📅 Appointment Scheduling
📋 Medical Records Management
🗄️ MS Access Database Integration
🖥️ User-Friendly Windows Interface
