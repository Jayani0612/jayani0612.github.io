🎓 Student Management System for ATI Tangalle
Software system | PHP | MySQL | HTML

Developed a web-based Student Management System for ATI Tangalle to manage student details, courses, and academic records efficiently. The system provides a secure login, an admin dashboard, and a user-friendly interface for managing academic data.

✨ Key Features
👤 Student Registration
📚 Course Management
📝 Academic Records Management
🔍 Search Functionality
🔐 Secure Admin Login
🗄️ MySQL Database Integration
